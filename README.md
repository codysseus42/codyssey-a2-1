# codyssey-a2-1
3팀 텀프로젝트 리포지토리

브리프(JSON) 한 개로 브랜드 네이밍, 슬로건, 스토리, 컬러 팔레트, 로고 시안까지 자동으로 생성하는 파이프라인입니다.

## 실행 방법

1. `cp .env.example .env`
2. `.env`에 `API_KEY` 입력 (발급: https://aistudio.google.com/apikey)
3. `pip3 install -r requirements.txt`
4. `python3 brand_generator.py`

Python 3.10 이상이 필요합니다.

## 파이프라인 구조

브리프 하나당 텍스트 생성 API를 5회, 이미지 생성 API를 3회 호출합니다.

- 텍스트 API (5회): 네이밍 → 슬로건 → 스토리 → 팔레트 → 로고 컨셉
- 이미지 API (3회): 로고 컨셉 3개마다 로고 시안 이미지 1장씩 생성

## 출력 파일

`output/<브리프 파일명>/` 아래에 다음이 생성됩니다.

- `brand_result.json` — 모든 스테이지 결과를 모은 최종 결과물
- `color_palette.png` — 컬러 팔레트 시각화 이미지
- `logo_01.png` ~ `logo_03.png` — 로고 시안 3장
- `pipeline/` — 스테이지별 원본 응답(JSON)
- `warning.txt` — 폴백 모델 사용, 개별 스테이지 실패 등 경고 로그

API 키 없이 결과물만 먼저 확인하고 싶다면 `output_sample/` 폴더를 참고하세요.

## 실행 결과

![대화형 실행 화면](readImage/실행.png)
잘못된 브리프 경로를 입력하면 다시 물어보고, 올바른 경로와 출력 폴더를 입력하면 네이밍부터 로고 이미지까지 6단계가 순서대로 진행되는 모습. 중간에 API가 503을 반환해 폴백 모델로 재시도하는 로그도 보인다.

![종료 화면](readImage/종료.png)
존재하지 않는 브리프 경로를 입력하면 다시 묻고, 0을 입력하면 프로그램을 종료하는 모습.

## 설계 판단

- 이미지 생성 API가 JPEG 바이트를 반환하므로, Pillow로 열어 PNG로 변환해 저장한다.
- 스테이지 하나가 실패해도 다음 단계를 계속 진행한다 (요구사항 9).
- API 응답이 429/500/503이면 폴백 모델로 1회 재시도하고, 폴백 모델이 사용됐다는 사실을 `warning.txt`에 기록한다.
- 각 스테이지의 프롬프트는 `prompts/*.txt`로 분리돼 있어 코드 수정 없이 프롬프트만 교체할 수 있다.
