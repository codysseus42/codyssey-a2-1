# toCatter — AI 멀티모달 10초 광고 제작

## 프로젝트 개요

가상 브랜드 **toCatter**(고양이용 캣닙 음료)의 10초 광고를, 모든 시각·청각 소스를 생성형 AI로 제작한 프로젝트입니다.
"기획 → 이미지 생성 → 이미지 편집/합성 → 영상 변환 → 오디오 생성 → 통합 편집"의 파이프라인을 직접 설계하고, 각 단계에서 도구를 선택한 근거와 실패·수정 과정을 기록했습니다.

| 구분 | 내용 |
|---|---|
| 브랜드 | toCatter — cat together |
| 제품 | 고양이 캣닙 음료 (240ml 캔) |
| 핵심 메시지 | "고양이도 가족이니까" |
| 구조 | 일상(공유) → 문제(소외) → 해결(참여) → 브랜드 |
| 가치 | 고양이용 음료를 함께하는 시간을 공유함으로서 가족으로 더 가깝게 느낄수 있음 |
| 길이 | 10초 / 4씬 |
| 사용 도구 | Claude · Midjourney · Gemini · Kling · ElevenLabs · Suno · CapCut |

### 파일명 규칙

```
asset(또는 scene)_종류_설명_원본시도번호_수정번호
```

- `asset_` : 여러 씬에 걸쳐 재사용되는 고정 소스
- `scene_` : 특정 씬 전용 소스
- 원본시도번호 = 새로 생성한 횟수, 수정번호 = 그 결과를 편집한 횟수
- 프레임·스크린샷·추출 파일은 시도/수정 번호를 갖지 않음

## 파라미터 표준

| 대상 | 고정값 | 목적 |
|---|---|---|
| 씬 이미지 비율 | `--ar 16:9` | 최종 영상 비율과 일치시켜 크롭 손실 방지 |
| 렌더 스타일 | `--raw` | Midjourney 자동 미화를 억제하고 실사 광고 톤 유지 |
| 스타일 강도 | `--stylize 120~130` | 미적 재해석보다 프롬프트 충실도 우선 |
| 변형 | `--weird 0` | 상업 광고에 부적합한 변형 배제 |
| 캐릭터 일관성 | `--ow 400` | Omni Reference 강도 상향으로 인물 동일성 확보 |
| 영상 해상도 | Kling 1080p | 전 클립 동일 해상도로 통일 |
| 영상 오디오 | Native Audio off (립싱크 씬만 on) | 크레딧 절약 + 오디오는 전용 도구로 제작 |

## 개념 정리

| 개념 | 설명 |
|---|---|
| T2I (Text to Image) | 텍스트로 이미지를 생성 |
| I2V (Image to Video) | 확정된 이미지에 모션을 부여해 영상으로 변환 |
| oref / `--ow` | 미드저니 파라메터 Omni Reference. 특정 인물·사물의 동일성을 유지하는 참조와 그 강도 |
| sref / `--sw` | 미드저니 파라메터 Style Reference. 색감·조명·질감만 참조 |
| Start / End Frame | I2V에서 시작·종료 시점의 화면을 지정해 카메라 움직임을 통제 |
| Voice Design | 텍스트 서술로 목소리 자체를 설계 |
| Voice Change (STS) | 원본 억양·타이밍을 유지한 채 목소리만 교체 |

### 서비스 별 파라미터

### Midjourney

| 파라미터 | 개념 | 값 범위 | 본 프로젝트 사용값 |
|---|---|---|---|
| `--ar` | Aspect Ratio. 출력 이미지의 가로세로 비율 | 자유 (1:1, 16:9 등) | 캐릭터 시트 3:4 / 인물 에셋 3:2 / 씬 16:9 |
| `--raw` (`--style raw`) | Midjourney가 기본 적용하는 미적 보정을 억제하고 프롬프트를 문자 그대로 해석 | on / off | 전 이미지 on |
| `--stylize` (`--s`) | 모델의 미적 재해석 강도. 높을수록 예뻐지지만 프롬프트에서 멀어짐 | 0~1000 (기본 100) | 120~130 |
| `--weird` (`--w`) | 비관습적·실험적 변형의 정도. 예측 불가능성을 의도적으로 높이는 값 | 0~3000 (기본 0) | 0 (변형 배제) |
| `--ow` | Omni Weight. Omni Reference로 지정한 인물·사물의 정체성을 얼마나 강하게 유지할지 | 1~1000 (기본 100) | 100 → 400 (아동 얼굴 일관성 확보) |
| `--sw` | Style Weight. Style Reference의 색감·조명·질감 반영 강도 | 0~1000 (기본 100) | 미사용 (구도까지 전이되어 oref로 교체) |
| `--iw` | Image Weight. Image Prompt가 텍스트 대비 갖는 영향력 | 0~3 (기본 1) | 미사용 (구도까지 참조되어 부적합) |
| `--no` | 특정 요소를 배제하는 부정 지시 | 텍스트 | 미사용 (위치 조건 해석 불가로 상태 서술 방식 채택) |

> **oref / sref / iw의 구분**
> 세 기능 모두 참조 이미지를 사용하지만 참조하는 대상이 다릅니다.
> `iw`(Image Prompt)는 이미지 전체를 구도까지 참조하고, `sw`(Style Reference)는 색감·조명·질감만,
> `ow`(Omni Reference)는 특정 인물·사물의 정체성만 참조합니다.

### Kling

| 파라미터 | 개념 | 선택지 | 본 프로젝트 사용값 |
|---|---|---|---|
| Mode | 출력 해상도 | 720p / 1080p | 1080p (전 클립 통일) |
| Length | 생성 영상 길이 | 3s / 5s / 10s | 3s (일부 5s) |
| Start Frame | 영상의 첫 프레임으로 사용할 이미지 | 이미지 업로드 | 확정된 씬 이미지 |
| End Frame | 영상의 마지막 프레임으로 지정할 이미지. 지정 시 두 프레임 사이를 보간 | 이미지 업로드 / 비움 | 컷 연결 구간만 지정, 나머지는 비움 |
| Number of Outputs | 1회 생성 시 만들어지는 결과 개수 | 1~4 | 1 (크레딧 절약) |
| Native Audio | 영상과 함께 음성·효과음을 생성. 립싱크의 전제 조건 | on / off | off (립싱크 씬만 on) |
| Multi-Shot | 한 생성 안에서 여러 컷으로 장면을 전환 | on / off | off (컷당 1클립 원칙) |
| Bind Elements | 특정 요소를 지정해 형태 붕괴를 억제 | 요소 선택 | 고양이 등장 클립에 적용 |

> **End Frame의 부작용**
> 시작·끝 프레임의 출처가 서로 다르면 모델이 두 배치의 차이를 보간하면서
> 존재하지 않던 사물이 생성되거나 정지 사물이 이동하는 아티팩트가 발생합니다.
> 따라서 두 프레임은 같은 원본에서 파생시키거나, 연결이 불필요하면 End Frame을 비웁니다.

### ElevenLabs

| 파라미터 | 개념 | 값 범위 | 본 프로젝트 사용값 |
|---|---|---|---|
| Model | 음성 생성 모델. 다국어 지원 여부가 갈림 | Multilingual v2 등 | Eleven Multilingual v2 (한국어) |
| Stability | 발화의 일관성. 낮으면 표현이 풍부하나 발음이 흔들리고, 높으면 억양이 평탄해짐 | 0~100% | 50% |
| Similarity Boost | 목표 보이스의 음색을 얼마나 강하게 재현할지 | 0~100% | 75% |
| Style Exaggeration | 보이스의 스타일 특성을 과장하는 정도. 원본 억양을 재해석함 | 0~100% | 0% (원본 억양 보존이 목적) |
| Speed | 발화 속도 | 0.7~1.2 | 1 (립싱크 입 모양과 동기화) |
| Speaker Boost | 화자 특성을 강조해 배경 성분의 영향을 줄임 | on / off | on (추출 음원이라 배경음 혼입) |
| Guidance Scale | Voice Design에서 텍스트 서술이 목소리에 반영되는 강도 | Low~High | 중상 (캐릭터성 확보) |
| Loudness | Voice Design에서 설계할 목소리의 기본 성량 | Quiet~Loud | 중하 (작게 묻는 톤) |

> **기능별 구분**
> `Text to Speech`는 텍스트에서 음성을 생성하고, `Voice Design`은 텍스트 서술로 목소리 자체를 설계하며,
> `Voice Change(Speech to Speech)`는 원본 음원의 억양·타이밍을 유지한 채 음색만 교체합니다.
> `Sound Effects`는 텍스트에서 비음성 효과음을 생성합니다.
